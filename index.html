My Pet Projects

  • API for “Thirteen Flies” e-commerce music store with Filament as admin panel

    Backend for a musical instruments store: a REST API (/api/v1) for a Next.js storefront, plus a Filament admin panel built from reusable fields and layouts. It has 4 languages, a nested category tree, product filters, brands, promotions, blog, services, authors, reviews and a wishlist. SEO is built in from day one: meta tag templates, robots.txt managed from the admin panel, a sitemap and a redirects module. Checkout is implemented with Stripe: a payment is confirmed only through a signed webhook, and after that the customer receives a confirmation email.

  • “Vanilla Core”: custom made MVC PHP framework

    A mini Laravel I wrote from scratch in plain PHP. It has a DI container that wires classes automatically using Reflection, a regex router with route groups, a middleware pipeline, Request/Response objects, a PDO model layer and a Blade-like template engine. Authentication is protected by built-in auth, guest and csrf middleware, plus session-fixation defence. I built it to see how a framework works from the inside.

  • “Sol4”: first social media for Mars colonists

    “Sol4: a new day on the 4th planet.” A Laravel + Blade social network where colonists can register, post photos, share short text thoughts; tag, like and comment posts and follow each other. I built it on purpose to design my first database by hand and use nearly every Eloquent relationship. It also has Policies and queued image optimization.

  • “MT Times”: NY Times but for Mars

    My first PHP pet project: a blog in vanilla PHP with its own admin panel. It has login and registration, roles and permissions (a super admin can edit any post, an admin only their own). Also CRUD with image uploads, CSRF protection and a small DI container. URLs are built with GET parameters, and that’s what later pushed me to write my own router.
